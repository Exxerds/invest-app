# Meta Pixel (Facebook Pixel) в инвестиционном проекте

Проект уже содержит готовую интеграцию Meta Pixel. ID пикселя `1633191371495886` вшит в код по умолчанию и будет работать на VPS сразу после сборки. Все события относятся к фронтенду (React + Vite), отдельные серверные события (CAPI) не настроены.

---

## 1. Что уже добавлено в код

| Файл | Что делает |
|---|---|
| `src/pixel.ts` | Загружает официальный скрипт `fbevents.js`, инициализирует пиксель и даёт функции отправки событий |
| `src/App.tsx` | Отправляет `PageView` при первой загрузке и при переключении разделов |
| `src/components/modals/LoginModal.tsx` | Отправляет `Login` при успешном входе |
| `src/components/modals/RegisterModal.tsx` | Отправляет `CompleteRegistration` после успешной регистрации |
| `src/components/modals/InvestModal.tsx` | Отправляет `InitiateCheckout`, когда пользователь подтверждает инвестицию |
| `src/App.tsx` | Отправляет `Purchase` после того как инвестиция успешно записана в систему |

> Любая из этих функций превращается в «пустую», если идентификатор пикселя не задан. Это сделано специально: вы можете спокойно тестировать проект без Meta Pixel.

## 2. Как подключить пиксель (ID уже вшит)

ID пикселя `1633191371495886` уже вставлен в `src/pixel.ts` как значение по умолчанию. Поэтому на VPS достаточно просто пересобрать проект — отдельный `.env` не нужен.

### Шаг 1. Заберите изменения на VPS

```bash
cd /путь/к/папке/invest-app
git pull origin main
npm install
npm run build
npm run start
```

### Шаг 2. Проверьте, что пиксель работает

1. Установите расширение **Meta Pixel Helper** в Chrome/Edge.
2. Откройте сайт — в расширении должен появиться ваш пиксель `1633191371495886` и событие `PageView`.
3. Откройте «Регистрация» и зарегистрируйтесь — должно появиться `CompleteRegistration` (или `Lead`, если выбрана цель «Лиды»).
4. Войдите в аккаунт — должно появиться `Login`.
5. Попробуйте инвестировать — после подтверждения должны появиться `InitiateCheckout` и `Purchase`.

### Если нужно переключить на другой ID

В корне проекта создайте файл `.env`:

```env
VITE_META_PIXEL_ID=1234567890123456
```

Подставьте нужный ID. Пересоберите проект (`npm run build`, затем `npm run start`). Файл `.env` уже в `.gitignore`.

## 3. Какие события уже настроены

| Событие | Когда отправляется |
|---|---|
| `PageView` | Загрузка сайта, открытие личного кабинета, CRM и т.д. |
| `InitiateCheckout` | Пользователь подтвердил ввод суммы инвестиции (до записи в систему) |
| `Purchase` | Инвестиция успешно создана (value = сумма, currency = USD) |
| `CompleteRegistration` | Пользователь успешно зарегистрировал аккаунт |
| `Login` | Пользователь успешно вошёл |

Для рекламных целей обычно используют одну из стандартных оптимизаций:

- **Лиды** → оптимизация на `CompleteRegistration` / `Lead`.
- **Продажи / конверсии** → оптимизация на `Purchase`.

## 4. Если захотите колбэк/момент после перехода по рекламе

Сейчас пиксель отправляет стандартные события. Дополнительно вы можете использовать параметры `fbclid` и `fbc` (cookie `_fbp`), но для базовой конверсии в лендинге их обычно не нужно дополнительно настраивать — Meta автоматически привязывает события к визиту через свои cookie.

## 5. Как добавить новое событие

В любой части фронтенда импортируйте функцию и вызовите её:

```ts
import { trackMetaPixel, trackCustomMetaPixel } from '../pixel';

// стандартное событие Meta
trackMetaPixel('Lead', {
  content_name: 'registration_form',
});

// своё событие
trackCustomMetaPixel('ButtonClicked', { button: 'start_invest' });
```

Пример с `content_id` и ценой:

```ts
trackMetaPixel('Purchase', {
  value: 1000,
  currency: 'USD',
  content_name: 'Stocks — S&P 500',
  content_type: 'product',
  content_ids: ['sp500'],
});
```

## 6. Частые вопросы

### Пиксель не отображается в Pixel Helper

1. Убедитесь, что на VPS выполнен `npm run build` после `git pull` — старый бандл не содержит пиксель.
2. Откройте сайт по прод-адресу, а не по старой статичной папке `dist`.
3. Перезапустите процесс (`npm run build && npm run start`).
4. Нажмите `Ctrl+Shift+R` (жёсткое обновление), чтобы браузер не держал старый JS-бандл.
5. Проверьте консоль браузера — при ошибке загрузки `fbevents.js` будет видно проблему с сетью.

### Вижу два PageView

В режиме React StrictMode может происходить дублирование эффекта в dev-режиме. На продакшен-сборке двойной отправки не будет. Лишние события в тесте можно очистить в Meta через **Менеджер событий → Тестовые события**.

### Нужно отключить пиксель

Удалите ID из `src/pixel.ts` (константа `DEFAULT_META_PIXEL_ID`) или задайте в `.env` пустой/неверный `VITE_META_PIXEL_ID`. Все вызовы станут no-op, сайт продолжит работать без изменений.

## 7. Что не сделано (по желанию)

- **Конверсионный API (CAPI)** — серверная отправка событий (например, после успешной покупки через API). Позволяет точнее измерять конверсии и обходить блокировщики. Требует Meta CAPI токен.
- **Динамический каталог** — автоматическая отправка товаров/услуг из каталога.
- **Пользовательские параметры** — например, передача `user_data` вручную для CRM-интеграции.
